# Flowcanvas

A canvas-first, AI-native development environment (working name). You see your app running as live frames on an infinite canvas, follow the real flow behind any element through code, data and services, and ask coding agents for changes you can review as behavioural diffs.

- **What's done, milestone by milestone, with the decisions made:** [`CHANGELOG.md`](CHANGELOG.md) (also shown in the app's What's new).
- **How to run it:** `pnpm install`, then `pnpm dev` (http://localhost:5173). Tests: `pnpm test`; walkthroughs `pnpm test:e2e`; the catalogue's accessibility check `pnpm test:a11y`; real containers `pnpm test:docker`.
